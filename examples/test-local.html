MakeWebsiteAIReady - Local Test Page

This page demonstrates the AI chatbot widget running against your local backend.

Setup Instructions:
  1. Open the dashboard at http://localhost:5173
  2. Register an account and log in
  3. Create a new site (e.g., "Test Site")
  4. Upload documents to your site for the RAG knowledge base
  5. Copy the Site Key from the site settings
  6. Replace YOUR_SITE_KEY_HERE in this page's source with your actual site key
  7. Reload this page - the chatbot widget will appear in the bottom-right corner

Sample Content

This is a sample website page. The AI chatbot widget will float in the bottom-right corner. Users can click it to ask questions, and the bot will answer using the documents you uploaded through the dashboard.

The widget communicates with your local backend at http://localhost:8000. Make sure both the backend and frontend servers are running.
